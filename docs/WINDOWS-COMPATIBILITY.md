# Windows compatibility

Backup Manager targets .NET 8 WPF and Windows Services. It is supported on Windows Server 2016, 2019, 2022, and 2025 with the .NET 8 Windows Desktop Runtime. Windows Server 2012 R2 is out of support for this target. Windows 2000/2003 cannot run modern .NET, WPF, current TLS, or current SFTP dependencies; a separate legacy native application with reduced security would be required and is not recommended.
